# **App Name**: Atmos

## Core Features:

- Live Weather Hub: Real-time display of temperature, conditions, humidity, and wind speed using live data from WeatherAPI or OpenWeatherMap.
- Intelligent Activity Advisor: An AI reasoning tool that analyzes current and forecasted conditions to suggest whether to carry an umbrella or plan outdoor activities.
- 5-Day Forecast Insight: Detailed multi-day weather outlook including high/low temperatures and predicted conditions presented in a scrollable view.
- Global City Discovery: A responsive search feature allowing users to instantly fetch and switch weather data for any global location.
- Geolocation Quick-Check: One-tap functionality to retrieve weather data based on the user's current GPS location coordinates.
- Dynamic Environment Engine: Adaptive backgrounds and glassmorphic UI elements that shift visually to match current conditions like storm, clear skies, or night.
- System-Matched Dark Mode: Modern dark and light mode toggle that seamlessly adjusts contrast for a premium reading experience in any lighting.

## Style Guidelines:

- Primary color: Celestial Blue (#87B9FF), chosen for its association with the open atmosphere and clarity.
- Background color: Deep Space (#12161F), a heavily desaturated dark blue-violet to emphasize glassmorphic transparency.
- Accent color: Neon Cyan (#3DE0FF), an analogous hue that provides high contrast and a contemporary tech-focused highlight.
- Headline font: 'Space Grotesk' (sans-serif) for high-impact metrics and temperatures; Body font: 'Inter' (sans-serif) for neutral, objective data labels.
- Clean, thin-line weather icons with soft glows to complement the premium glassmorphism aesthetic.
- Glassmorphic cards with heavy backdrop blur (20px+) and thin semi-transparent white borders on a fluid, mobile-first responsive grid.
- Staggered layout entrances for cards and subtle parallax motion on the dynamic background scenes when weather states change.
